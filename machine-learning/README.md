# 🤖 Machine Learning for Analysts

Machine learning is included as an extension of the analytics workflow, not as a replacement for understanding the data.

## Fundamentals

- Train / validation / test concepts
- Features and target
- Categorical encoding
- Scaling and preprocessing
- Feature engineering
- Regression
- Classification
- Overfitting and underfitting
- Cross-validation fundamentals

## Evaluation

### Regression
- MAE
- MSE
- RMSE
- R²

### Classification
- Accuracy
- Precision
- Recall
- F1-score
- Confusion matrix
- ROC-AUC where appropriate

## Analyst Workflow

**Business problem → Data preparation → Baseline → Model → Evaluation → Error analysis → Interpretation → Business decision**

Always compare model performance with a sensible baseline and explain the cost of false positives and false negatives when relevant.
