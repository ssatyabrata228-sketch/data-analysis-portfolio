# 💼 Data Analyst Interview Preparation

## 1. SQL

Be ready to explain and write:
- WHERE vs HAVING
- INNER JOIN vs LEFT JOIN
- GROUP BY
- CASE WHEN
- Subqueries
- CTEs
- Window functions
- ROW_NUMBER, RANK, DENSE_RANK
- Running totals
- Top-N analysis
- Duplicate detection
- NULL handling

## 2. Python / Pandas

Practice:
- Loading CSV/Excel files
- `head()`, `info()`, `describe()`
- Missing values
- Duplicates
- `groupby()` and aggregation
- `merge()` / joins
- `pivot_table()`
- Datetime operations
- Filtering and sorting
- EDA and visualization

## 3. Excel

Know:
- XLOOKUP / INDEX-MATCH
- SUMIFS / COUNTIFS
- IF / IFS
- PivotTables
- Charts
- Conditional formatting
- Data cleaning
- Dashboard design

## 4. Power BI

Know how to explain:
- Power Query
- Data modeling
- Relationships
- Star schema
- Measures vs calculated columns
- DAX basics
- Filter context
- Slicers and drill-through
- KPI design

## 5. Statistics

Prepare:
- Mean vs median
- Standard deviation
- Outliers
- Correlation vs causation
- Probability
- Sampling
- Confidence intervals
- Hypothesis testing
- p-value
- A/B testing

## 6. Project Questions

For every project, prepare a 2-minute explanation:

1. What was the problem?
2. What was the dataset?
3. What cleaning did you perform?
4. Which tools did you use and why?
5. What were the most important findings?
6. What business recommendations did you make?
7. What was difficult?
8. What would you improve?

## 7. Behavioral Questions

Prepare concise STAR-format answers for:
- Tell me about yourself.
- Why Data Analysis?
- Why should we hire you?
- Describe a difficult project.
- Tell me about a mistake and what you learned.
- How do you handle unclear requirements?
- How do you communicate technical findings to non-technical people?

## Final Interview Rule

Do not memorize answers without understanding them. Explain your assumptions, show your reasoning, and be honest about what you know and what you are still learning.
