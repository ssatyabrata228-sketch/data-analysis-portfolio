# 📗 Excel for Data Analysis

## Essential Skills

- Tables and structured references
- Sort and Filter
- Remove Duplicates
- Text to Columns
- Data Validation
- Conditional Formatting
- IF / IFS
- SUMIFS / COUNTIFS / AVERAGEIFS
- XLOOKUP and INDEX/MATCH
- TEXT, LEFT, RIGHT, MID and TRIM
- Date and time functions
- PivotTables and PivotCharts
- Charts and KPI cards
- Dashboard layout and usability

## Dashboard Checklist
- Define the audience and business question.
- Put the most important KPIs at the top.
- Use consistent labels and number formats.
- Avoid unnecessary chart types and decoration.
- Add filters only when they improve analysis.
- Include a short insight/recommendation section.
- Validate totals against the source data.
