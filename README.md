## 🚀 Project Quality Standard

Every completed major project should include:

- Problem statement / business objective
- Dataset source and data dictionary
- Data cleaning and validation
- Exploratory Data Analysis
- SQL analysis where applicable
- Visualizations / dashboard
- Key findings
- Business recommendations
- Limitations and assumptions
- Reproducible instructions

A strong project should answer:

1. **What happened?** — descriptive analysis
2. **Why did it happen?** — diagnostic analysis
3. **What should we do next?** — actionable recommendations
