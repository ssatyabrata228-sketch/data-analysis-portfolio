# 📊 Dashboard Standards

A professional dashboard should help a user make a decision quickly.

## Before Building

- Define the target audience.
- Define the business question.
- Define the primary KPIs.
- Confirm metric definitions.
- Check the grain of the data.

## Recommended Layout

1. **KPI summary** — revenue, orders, customers, conversion, or other relevant measures.
2. **Trend** — performance over time.
3. **Breakdown** — category, region, product, customer segment, etc.
4. **Drivers** — factors explaining changes.
5. **Details** — supporting table where needed.
6. **Recommendations** — what action should be considered.

## Dashboard Checklist

- [ ] Every visual answers a question.
- [ ] Titles communicate the metric and context.
- [ ] Units and date ranges are visible.
- [ ] Filters are useful and understandable.
- [ ] KPI calculations are validated.
- [ ] No misleading axes or unnecessary decoration.
- [ ] Accessibility and readability are considered.
- [ ] Business recommendations are documented.
