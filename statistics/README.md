# 📐 Statistics for Data Analysts

## Descriptive Statistics
- Mean: arithmetic average
- Median: middle value after sorting
- Mode: most frequent value
- Range: maximum − minimum
- Variance: average squared deviation from the mean
- Standard deviation: square root of variance
- Percentiles: values dividing ordered observations into proportions

## Concepts to Understand

### Distribution
Understand center, spread, skewness, tails and outliers rather than relying only on the mean.

### Correlation
Correlation describes association between variables. It does **not** by itself establish causation.

### Hypothesis Testing
A typical workflow:
1. Define the business question.
2. State null and alternative hypotheses.
3. Select an appropriate test.
4. Set a significance level before testing.
5. Calculate the test statistic / p-value.
6. Interpret the result in business context.
7. Report uncertainty and limitations.

### Confidence Intervals
A confidence interval communicates uncertainty around an estimate. Report both the estimate and interval where appropriate.

### A/B Testing
Compare a control and treatment group using a pre-defined primary metric, appropriate statistical test, sample-size considerations, and practical significance.

## Analyst Warning
Statistical significance is not the same as business significance. Always consider effect size, uncertainty, data quality, sampling, and the decision the analysis is intended to support.
