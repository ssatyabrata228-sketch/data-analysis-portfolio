# 🗺️ Data Analyst Learning Roadmap

## Phase 1 — Excel
- Workbook structure and data types
- Relative/absolute references
- IF, SUMIFS, COUNTIFS, XLOOKUP/INDEX-MATCH
- Text and date functions
- Data cleaning
- Conditional formatting
- PivotTables and PivotCharts
- KPI and dashboard design

## Phase 2 — SQL
- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- CASE statements
- INNER/LEFT/RIGHT/FULL JOIN concepts
- Subqueries
- CTEs
- Window functions
- Date/string functions
- NULL handling
- Business case studies

## Phase 3 — Statistics
- Mean, median, mode
- Variance and standard deviation
- Percentiles and distributions
- Probability fundamentals
- Sampling
- Correlation vs causation
- Confidence intervals
- Hypothesis testing and p-values
- A/B testing fundamentals

## Phase 4 — Python for Data Analysis
- Python fundamentals
- NumPy
- Pandas
- Data cleaning
- Missing values and duplicates
- GroupBy and aggregation
- Merge/join/concat
- Date-time analysis
- Matplotlib and Seaborn
- Exploratory Data Analysis

## Phase 5 — Power BI
- Power Query
- Data transformation
- Star schema and relationships
- Measures vs calculated columns
- DAX fundamentals
- Time intelligence fundamentals
- KPI cards and interactive reports
- Dashboard storytelling

## Phase 6 — Portfolio Projects
Build at least:
1. Sales / business performance analysis
2. Customer / marketing analysis
3. HR / employee analytics
4. SQL case study
5. Power BI dashboard
6. One end-to-end project combining SQL + Python + Power BI

## Phase 7 — Interview Preparation
- SQL timed practice
- Python/Pandas questions
- Excel questions
- Power BI/DAX questions
- Statistics questions
- Business case studies
- Project walkthroughs
- Behavioral/HR questions

## Quality Checklist
Before calling a project complete:
- [ ] Problem is clearly defined
- [ ] Data source is documented
- [ ] Data quality checks are performed
- [ ] Cleaning decisions are explained
- [ ] Analysis answers business questions
- [ ] Charts have meaningful titles and labels
- [ ] Insights are supported by numbers
- [ ] Recommendations are actionable
- [ ] Limitations are documented
- [ ] README explains how to reproduce the work
