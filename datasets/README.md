# 🗃️ Dataset Management

## Dataset Documentation Standard

For every dataset used in a project, document:

- Dataset name
- Source / attribution
- Access date when relevant
- License / usage terms when available
- Number of rows and columns
- Time period
- Important fields
- Known quality issues
- Transformation history

## Recommended Practice

Do not upload sensitive, confidential, copyrighted, or unnecessarily large raw datasets. Prefer linking to the original public source or providing a small synthetic/sample dataset when possible.

## Data Quality Checklist

- [ ] Schema reviewed
- [ ] Data types validated
- [ ] Missing values measured
- [ ] Duplicate records checked
- [ ] Invalid categories checked
- [ ] Numeric ranges checked
- [ ] Date ranges checked
- [ ] Key uniqueness checked
- [ ] Join keys validated
- [ ] Data source documented
