# Contributing / Portfolio Standards

This repository is primarily a personal learning and portfolio project.

## Standards for New Work

- Use clear file and folder names.
- Add a README to substantial projects.
- Document the dataset source.
- Explain cleaning and analytical assumptions.
- Keep notebooks organized and reproducible.
- Do not commit passwords, API keys, tokens or private information.
- Do not claim results that cannot be reproduced or verified.
- Prefer meaningful commits such as `Add sales EDA` or `Improve customer SQL case study`.

## Project Review Checklist

Before considering work complete, review:

- Data quality
- Code readability
- Analytical correctness
- Visualization quality
- Business interpretation
- Documentation
- Reproducibility
